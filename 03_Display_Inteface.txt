SNAPACK Hardware Specification

============================================================
PURPOSE
============================================================

This Specification Defines The Electrical And Mechanical
Interface Between The ELECROW Display Assembly And The
SNAPACK Controller Hardware.

Display Connector Assignments Are Defined Separately In:

    01_Authoritative_Pin_Mapping.txt

============================================================
DISPLAY ASSEMBLY
============================================================

Display

    ELECROW ESP32-S3 Rotary Display

Features

• ESP32-S3 Processor

• Capacitive Touchscreen

• Rotary Encoder

• RGB LED Ring

• Integrated USB

• WiFi

• Bluetooth

============================================================
DISPLAY CONNECTION
============================================================

The Display Connects To The SNAPACK Interface Board
Using The Factory 12-Pin Ribbon Cable.

The Ribbon Cable Connects Through A Straight-Through
Breakout Board.

Only The Display Ribbon Connector Pin Numbers Shall
Be Used Within SNAPACK Documentation.

Breakout Board Pin Numbers Are Not Used Except During
Physical Construction.

============================================================
COMMUNICATIONS
============================================================

I2C

SCL

SDA

Used For:

• ADS1115 Board 1

• ADS1115 Board 2

Additional I2C Devices May Be Added In The Future.

------------------------------------------------------------

Temperature Bus

OneWire

Used For:

DS18B20 Temperature Sensors

------------------------------------------------------------

USB

Reserved

Not Used During Normal Operation.

============================================================
POWER
============================================================

Display Power

5V Regulated Supply

Logic Voltage

3.3V Internal Logic

The Display Shall Never Receive Battery Voltage Directly.

============================================================
DISPLAY FUNCTIONS
============================================================

The Display Provides:

• Touch Interface

• Rotary Encoder Input

• RGB Status Ring

• Visual Alarm Indication

• System Status Display

• Bluetooth Configuration

• WiFi Configuration

============================================================
DISPLAY SCREENS
============================================================

Primary Dashboard

Displays

• Battery Voltage

• Current

• Temperature

• System Status

------------------------------------------------------------

Large Current Screen

Automatically Displays During High Current Events.

Large Numeric Display Visible During Vehicle Cranking.

------------------------------------------------------------

Configuration Screens

Display User Adjustable Settings.

============================================================
STATUS INDICATION
============================================================

The RGB Ring May Be Used To Indicate Overall
System Status.

Typical Semantic Colors

Green

Normal

Yellow

Warning

Red

Fault

Animated Effects May Be Used During Startup Or
Normal Operation.

============================================================
MECHANICAL NOTES
============================================================

The Display Shall Be Mounted Such That The
Ribbon Cable Is Not Subjected To Mechanical
Stress.

The Ribbon Cable Shall Include Adequate
Strain Relief.

Repeated Removal Of The Ribbon Cable Should
Be Minimized To Prevent Damage To The ZIF
Connector Locking Mechanism.

============================================================
VERIFICATION
============================================================

Verify

□ Display Powers Correctly

□ Touchscreen Operates

□ Rotary Encoder Operates

□ RGB Ring Operates

□ I2C Communication Established

□ Temperature Bus Functional

□ Ribbon Connector Fully Seated

□ No Mechanical Stress On Ribbon Cable

END OF SPECIFICATION
