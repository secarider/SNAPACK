PURPOSE
============================================================

This Specification Defines The Complete Analog Voltage
Measurement System Used By SNAPACK.

It Covers:

• ADS1115 Data Acquisition
• Voltage Divider Networks
• Input Protection
• Current Sensor Interface
• Pack Voltage Measurement
• Output Voltage Measurement

Connector Assignments Are Defined In:

    01_Authoritative_Pin_Mapping.txt

============================================================
SYSTEM OVERVIEW
============================================================

The Analog Front End Continuously Measures Battery,
Output And Current Sensor Signals.

ADS1115 16-Bit Analog-To-Digital Converters
Provide Measurement Channels.

All External Voltage Inputs Use A Protection 
Network Prior To Entering The ADS1115.

============================================================
CHANNEL ALLOCATION
============================================================

Board 1 — 0x48 jumper directly between ADDR Pin To SYS GND

A0 = B1
A1 = B2
A2 = B3
A3 = B4
this is all 4 cells that make 12v on one board

ALERT Wired And Available

------------------------------------------------------------

Board 2 — 0x49 jumper directly between ADDR Pin To VDD

A0 = B5 Pack Positive +
A1 = CDS/light sensor
A2 = OTC Current
A3 = 24 V LEV100 supply monitor

ALERT Wired And Available

------------------------------------------------------------

Board 3 — 0x4A jumper directly between ADDR Pin To SDA

A? =    Final Output +
A? =    Final Output −
two spare channels remaining

ALERT Wired And Available

============================================================
Address Assignment Method:
============================================================

Board 1 = 0x48 jumper directly between ADDR Pin To SYS GND
Board 2 = 0x49 jumper directly between ADDR Pin To VDD
Board 3 = 0x4A jumper directly between ADDR Pin To SDA
Board 4 = 0x4B jumper directly between ADDR Pin To SCL

============================================================
INPUT PROTECTION
============================================================

Every Voltage Measurement Channel Uses A Protection Network.

Components

Current proven divider architecture:

B1:
47k high / 18k low

B2:
47k high / 18k low

B3:
47k high / 18k low

B4:
100k high / 10k low

B5:
100k high / 10k low

Design maximum cumulative voltages:

B1 = 3.65 V
B2 = 7.30 V
B3 = 10.95 V
B4 = 14.60 V
B5 = 18.25 V

These values describe the present proven implementation and required
measurement ranges.

P6KE18A TVS Diode

100nF Filter Capacitor

Every Voltage Measurement Channel Uses A Protection/Filtering Network.

============================================================
CURRENT SENSOR INPUT
============================================================

The OTC Hall Current Sensor Provides An Analog
Voltage To ADS1115 Board 2.

The Current Sensor Uses Its Own Power
Supply Defined In:

    05_Current_Monitoring.txt And
    02_Power_Architecture.txt

============================================================
OUTPUT VOLTAGE MONITORING
============================================================

The Remaining Two ADS1115 Channels Monitor

These Are At The Last Point Before Leaving Pack Behind All Contactors

• Final Output Positive

• Final Output Negative

These Measurements Allow Firmware To Determine

Actual Output Voltage To Confirm Mode Selection
This Will Change From 12 To 16 In Boost Mode

Voltage Drop

Pack Internal Resistance

System Performance Under Load

============================================================
I²C INTERFACE
============================================================

ADS1115 Boards Operate On The Shared I²C Bus 3.3v Only

============================================================
ALERT OUTPUT
============================================================

ADS1115 Board 1 ALERT Output Connects To

AITRIP 5V Opto-Isolated Relay Module

The Relay Module Interrupts The Contactor pos+
Authorization Circuit During Hardware Fault
Conditions.
