============================================================
PURPOSE
============================================================

This Specification Defines The Complete Analog Voltage
Measurement System Used By SNAPACK.

It Covers:

• ADS1115 Data Acquisition
• Voltage Divider Networks
• Input Protection
• Current Sensor Interface
• Pack Voltage Measurement
• Output Voltage Measurement

Connector Assignments Are Defined In:

    01_Authoritative_Pin_Mapping.txt

============================================================
SYSTEM OVERVIEW
============================================================

The Analog Front End Continuously Measures Battery,
Output And Current Sensor Signals.

Two ADS1115 16-Bit Analog-To-Digital Converters
Provide Eight Measurement Channels.

All External Voltage Inputs Use An Identical
Protection Network Prior To Entering The ADS1115.

CHANNEL ALLOCATION
============================================================

------------------------------------------------------------

Board 2

A1 = Final Output +

A2 = OTC Current

A3 = Final Output −

============================================================
INPUT PROTECTION
============================================================

Every Voltage Measurement Channel Uses The Same
Protection Network.

Components

P6KE18A TVS Diode

47kΩ 1W Series Resistor

18kΩ Divider Resistor

100nF Filter Capacitor

This Network Is Used For Every Battery And Output
Voltage Measurement Channel.

============================================================
CURRENT SENSOR INPUT
============================================================

The OTC Hall Current Sensor Provides An Analog
Voltage To ADS1115 Board 2.

The Current Sensor Uses Its Own Isolated Power
Supply Defined In:

    05_Current_Monitoring.txt

============================================================
OUTPUT VOLTAGE MONITORING
============================================================

The Remaining Two ADS1115 Channels Monitor

• Final Output Positive

• Final Output Negative

These Measurements Allow Firmware To Determine

Output Voltage

Voltage Drop

Pack Internal Resistance

System Performance Under Load

============================================================
I²C INTERFACE
============================================================

Both ADS1115 Boards Operate On The Shared I²C Bus.

Communication Is Through The Logic Level Shifter.

============================================================
ALERT OUTPUT
============================================================

ADS1115 Board 1 ALERT Output Connects To

AITRIP 5V Opto-Isolated Relay Module

The Relay Module Interrupts The Contactor
Authorization Circuit During Hardware Fault
Conditions.

============================================================
DESIGN REQUIREMENTS
============================================================

All Voltage Inputs Shall Use Identical Protection
Networks.

Only Protected Signals Shall Enter The ADS1115.

All Analog Measurements Shall Reference System
Ground Except The Isolated OTC Interface.

The B0509S-1WR3 isolated 5V → 9V converter requires a minimum output load
for operation within its specified performance range.

Bench testing confirmed successful 5V → 9V operation with two 1 kΩ resistors
connected in parallel across the isolated 9V output.

The two 1 kΩ resistors shall remain installed as a permanent minimum-load
preload rather than being treated as temporary test components.
