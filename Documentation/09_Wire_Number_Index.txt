SNAPACK Hardware Specification

Status: Authoritative
Revision: Draft 1

============================================================
PURPOSE
============================================================

This Specification Defines The Master Wire Number
Index For SNAPACK.

Every Permanently Installed Wire Shall Have A
Unique Wire Number.

This Document Serves As The Master Cross Reference
For All Electrical Wiring.

============================================================
WIRE IDENTIFICATION STANDARD
============================================================

Each Wire Entry Shall Include

Wire Number

Wire Color

Wire Gauge

Signal Name

Source

Destination

Specification Reference

Notes (Optional)

============================================================
WIRE NUMBER FORMAT
============================================================

Wire Numbers Shall Be Sequential.

Each Number Shall Refer To One Physical Wire Only.

Wire Numbers Shall Not Be Reused.
