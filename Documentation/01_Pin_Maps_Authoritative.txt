============================================================
            PIN NUMBERING CONVENTION
============================================================

Unless Specifically Stated Otherwise:

All ELECROW Display Pin Numbers Refer To The 12-Pin Ribbon Cable
Connector Pin Numbers As Identified By The Silkscreen On The Back
Of The Display PCB.

The Ribbon Breakout Board Is Treated Strictly As A Straight-Through
Extension Of The Display Ribbon Cable. However,
A 3 Pin JST Female Connector/Header Has Been Attached To The 
Breakout Board At Pins D+, D-, Ground. !! NO POWER LINE !!
A Corresponding USB Type A Plug Has Been Fitted With 
The Matching Connection To Create A Computer/Flashing Path
That Does Not Interfere With The Packs Normal Power Paths.

Breakout Board Pin Numbers Are Intentionally NOT Used In This
Manifest Unless Absolutely Required For Physical Construction.

CHANNEL ALLOCATION
============================================================
Board 1 — 0x48 jumper directly between ADDR Pin To SYS GND
A0 = B1
A1 = B2
A2 = B3
A3 = B4
this is all 4 cells that make 12v on one board

ALERT Wired And Available

------------------------------------------------------------

Board 2 — 0x49 jumper directly between ADDR Pin To VDD
A0 = B5 Pack Positive +
A1 = CDS/light sensor
A2 = OTC Current
A3 = 24 V LEV100 supply monitor

ALERT Wired And Available

------------------------------------------------------------

Board 3 — 0x4A jumper directly between ADDR Pin To SDA
A? =    Final Output +
A? =    Final Output −
two spare channels remaining

ALERT Wired And Available
