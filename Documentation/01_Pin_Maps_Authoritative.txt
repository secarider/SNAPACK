============================================================
            PIN NUMBERING CONVENTION
============================================================

Unless Specifically Stated Otherwise:

All ELECROW Display Pin Numbers Refer To The 12-Pin Ribbon Cable
Connector Pin Numbers As Identified By The Silkscreen On The Back
Of The Display PCB.

The Ribbon Breakout Board Is Treated Strictly As A Straight-Through
Extension Of The Display Ribbon Cable.

Breakout Board Pin Numbers Are Intentionally NOT Used In This
Manifest Unless Absolutely Required For Physical Construction.

The Two Custom Perfboard Headers Are Identified Separately As:

10 Pin Input Header
10 Pin Output Header

The Following Three Pin Maps Are Authoritative And Supersede Any
Older Or Conflicting Pin Number References Elsewhere.

============================================================
               10 PIN INPUT HEADER
============================================================

Pins 1-4 Were Previously Used For Duplicate B0509S-1WR3
5V Input And Isolated 9V Output Connections.

The B0509S-1WR3 Now Uses Two Dedicated Perfboard-Mounted
2-Pin Headers:

Pin 01: RETIRED / NO CONNECTION / EMPTY
Pin 02: RETIRED / NO CONNECTION / EMPTY
Pin 03: RETIRED / NO CONNECTION / EMPTY
Pin 04: RETIRED / NO CONNECTION / EMPTY
Pin 05: B0 Pack Ground / System Ground
Pin 06: B1 Cell 1 Cumulative Voltage ~3V
Pin 07: B2 Cell 2 Cumulative Voltage ~6V
Pin 08: B3 Cell 3 Cumulative Voltage ~9V
Pin 09: B4 Cell 4 Cumulative Voltage ~12V
Pin 10: B5 Cell 5 Cumulative Voltage ~16V / Pack Positive

============================================================
              10 PIN OUTPUT HEADER
============================================================

Pin 01: System Ground
Pin 02: BMS / Voltage Divider Isolation Coils Positive 12V+
Pin 03: Alert / Alarm From ADS1115 Board 1
Pin 04: OPEN / NO CONNECTION / EMPTY
Pin 05: 5V Power
Pin 06: SCL 3.3V Logic
Pin 07: SDA 3.3V Logic
Pin 08: Temperature Sensor Data
Pin 09: Output Voltage Sense (+)
Pin 10: Output Voltage Sense (−)

============================================================
              12 PIN RIBBON CABLE
============================================================

Pin 12: System Common Ground
Pin 11: System Common Ground
Pin 10: D+ USB Data Positive — OPEN / NO CONNECTION / EMPTY
Pin 09: D- USB Data Negative — OPEN / NO CONNECTION / EMPTY
Pin 08: SCL 3.3V I2C Clock
Pin 07: SDA 3.3V I2C Data
Pin 06: TX Temperature Sensor Data Target
Pin 05: RX OPEN / NO CONNECTION / EMPTY
Pin 04: NC OPEN / NO CONNECTION / EMPTY
Pin 03: NC OPEN / NO CONNECTION / EMPTY
Pin 02: 5V 5V Main Power Input
Pin 01: 5V 5V Main Power Input

          ADS1115 AUTHORITATIVE CHANNEL MAP
============================================================
CHANNEL ALLOCATION
============================================================
Board 1 — 0x48 jumper directly between ADDR Pin To SYS GND
A0 = B1
A1 = B2
A2 = B3
A3 = B4

------------------------------------------------------------

Board 2 — 0x49 jumper directly between ADDR Pin To 5v+ VDD
A0 = B5
A1 = Final Output +
A2 = OTC Current
A3 = Final Output −

------------------------------------------------------------

Board 3 — 0x4A jumper directly between ADDR Pin To SDA
A0 = 24 V LEV100 supply monitor
A1 = one channel for the CDS/light sensor
two spare channels remaining
