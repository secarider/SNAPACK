SNAPACK Hardware Specification

Status: Authoritative
Revision: Draft 1

============================================================
PURPOSE
============================================================

This Specification Defines The Hardware Used To
Measure Pack Current.

It Covers:

• OTC Hall Effect Current Sensor
• Analog Signal Interface
• Mechanical Installation

Electrical Connections Are Defined In:

    01_Authoritative_Pin_Mapping.txt

============================================================
SYSTEM OVERVIEW
============================================================

SNAPACK Uses A Hall Effect Clamp Current Sensor
To Measure Charge And Discharge Current Without
Direct Electrical Connection To The Main Power
Conductors.

The Sensor Provides A Continuous Analog Output
To The ADS1115 Analog Front End.

============================================================
HARDWARE
============================================================

Current Sensor

OTC 3500-01 Hall Effect Clamp

Measurement Type

Bi-Directional DC Current

Output

Analog Voltage

============================================================
POWER
============================================================

The Current Sensor Operates From A 9V Power Supply.

============================================================
SIGNAL INTERFACE
============================================================

The OTC Analog Output Connects To

ADS1115 Board 2

Channel A2

Signal Conditioning Is Defined In

04_ADS1115_Analog_Front_End.txt

============================================================
MECHANICAL INSTALLATION
============================================================

The Clamp Shall Be Installed Around The Main
Output Conductor Positive Path.

Clamp Orientation Has Been Determined And Marked.

Adequate Strain Relief Shall Be Provided For
The Sensor Cable.

============================================================
MEASUREMENT PURPOSE
============================================================

Current Measurement Supports

• Output Current

• Charge Current

• Reverse Current

• Cranking Current

• Internal Resistance Calculations

• Protection Functions

============================================================
CALIBRATION
============================================================

The Sensor Shall Be Zeroed During Initial
Calibration.

Calibration Values Shall Be Stored By Software.

============================================================
END OF SPECIFICATION
