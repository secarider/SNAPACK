NOTE:
For Elecrow-specific/display libraries where an exact version is
not recorded above, preserve the currently installed known-good
Elecrow versions rather than automatically upgrading them.

LVGL CONFIGURATION
------------------
SNAPACK uses the active Arduino LVGL installation at:

~/Arduino/libraries/lvgl

The Elecrow-compatible lv_conf.h configuration is also required.

FLASH / RECOVERY TOOL
---------------------
esptool: 5.3.1 installed via pipx

Known-good executable:
~/.local/bin/esptool

For the original 16 MB factory backup, --no-stub was required.

ARCHIVED SNAPACK ZIP FILES
--------------------------
Each numbered SNAPACK firmware ZIP is a complete source snapshot
of that revision.

The ZIP does NOT contain:
- Arduino IDE
- ESP32 Arduino Core
- installed Arduino libraries
- board packages / toolchains

Therefore this dependency/version sheet should be kept with the
firmware archive.

UPDATE POLICY
-------------
Do NOT assume newer versions are drop-in compatible.

In particular, preserve:
    ESP32 Arduino Core 2.0.14
    LVGL 8.3.6
    GFX Library for Arduino 1.3.1

A future upgrade should be treated as a deliberate SNAPACK
development change, not routine maintenance.
